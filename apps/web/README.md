# web

Angular 22 client for the Vehicle Maintenance Tracker: standalone components, zoneless change detection, signals, PrimeNG (Aura theme), Vitest.

| Folder | Holds |
|---|---|
| `src/app/api/` | Client generated by `scripts/generate-api-client.sh` from the API's OpenAPI document (never edited by hand) |
| `src/app/core/auth/` | `AuthState` over `sessionStorage`, the bearer interceptor, the route guard |
| `src/app/core/layout/` | The email-verification banner shown to signed-in, unverified users |
| `src/app/features/auth/` | Register, login, verify, forgot-password, reset-password screens over the `AuthApi` facade |
| `src/app/features/vehicles/` | `VehiclesFacade`, the list with its form dialog and delete confirmation, the detail page |
| `src/app/features/maintenance/` | `MaintenanceFacade` and the log/edit dialog used by the vehicle detail page |
| `src/app/shared/` | `problem-details.ts`, the one mapper from API errors to form and field messages |

Run `npm test` here, or `scripts/dev.sh` from the repository root for `ng serve` on http://localhost:4200 with `/api` proxied to the API through `proxy.conf.json`. `src/environments/` keeps the API root URL empty in both builds because the API is always reached on the same origin, through the dev proxy or Nginx.
